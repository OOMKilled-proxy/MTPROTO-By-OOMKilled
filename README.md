# ⚡ MTPROTO By OOMKilled

Автономный комбайн для быстрого развертывания высокоскоростного **MTProto-прокси с поддержкой Fake-TLS (TLS 1.3)** и встроенной **FastAPI веб-панелью мониторинга**.

 Без тяжелых контейнеров Docker, с автоматическим тюнингом сетевого стека ядра Linux и генерацией прямых Telegram-ссылок с ASCII QR-кодами прямо в терминале.

---

## 🚀 Быстрый запуск (в одну команду)

Подключитесь к вашему VPS под пользователем `root` и выполните:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/OOMKilled-proxy/MTPROTO_By_OOMKilled/main/mtproto_by_oomkilled.sh)"
```

Или 

```bash
curl -fsSL https://raw.githubusercontent.com/OOMKilled-proxy/MTPROTO_By_OOMKilled/main/mtproto_by_oomkilled.sh -o /usr/local/bin/oom && chmod +x /usr/local/bin/oom && oom
```
> После этого вызывать панель управления можно будет простой командой `oom` из любого каталога.

## 🛠 Возможности

* **Fake-TLS (Эмуляция TLS 1.3)**: Защита от глубокого анализа пакетов (DPI) и систем цензуры через маскировку трафика под популярные зарубежные сервисы (Cloudflare, Google, Wikipedia).
* **Встроенный веб-дашборд**:
  * Мониторинг нагрузки на CPU и RAM в реальном времени.
  * Подсчет активных пользовательских соединений (TCP ESTABLISHED).
  * Генерация персональных секретов и удаление пользователей в один клик.
  * Защита интерфейса через HTTP Basic Auth.
* **Автономный Fixer & Optimizer**:
  * Автоматический тюнинг `TCP FastOpen` и лимитов дескрипторов `fs.file-max=65536`.
  * Принудительное открытие портов в `iptables` и `ufw`.
  * Сброс зависших сессий на используемом порту через `fuser`.
* **Терминальный QR-код**: Компактный UTF-8/ASCII QR-код для мгновенного добавления прокси в клиенты Telegram на смартфонах.
* **Изолированное окружение**: Ядро прокси и веб-панель работают в выделенном Python virtualenv (`/opt/mtproto_by_oomkilled/venv`), не засоряя глобальную систему.

## 📋 Системные требования

* **ОС**: Ubuntu 20.04 / 22.04 / 24.04 LTS или Debian 11 / 12
* **Архитектура**: x86_64 (amd64) или ARM64
* **Права**: `root` (или пользователь с `sudo`)
* **Свободные порты**: 
  * Порт прокси (по умолчанию `443/TCP`)
  * Порт панели (по умолчанию `8080/TCP`)

---

## 🔒 Важно: настройка брандмауэра

Если прокси или веб-панель не открываются после установки, убедитесь, что соответствующие порты открыты во внешнем сетевом экране вашего хостинга (Security Groups / Firewall):

* **443 TCP** — входящий трафик для клиентов Telegram.
* **8080 TCP** — входящий трафик для доступа к веб-интерфейсу.
